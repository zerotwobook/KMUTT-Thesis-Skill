# Citations and bibliography — grounded in the supplied KMUTT 2556 manual

**Source:** printed pp. 14–23, corresponding PDF pp. 16–25.
**HARD CHOICE:** use either the numbered system or the author–year system **consistently**. Do not mix in-text `[1]` with `(Smith, 1999)` except when discussing example text.

## 1. Numbered system (ระบบหมายเลข)
**RULE**, printed p. 14 (PDF 16):
- In-text square brackets for citation numbers, e.g. `[1]`, `[2]`; multiple source numbers in the same reference point may be combined e.g. `[1, 2, 3]`.
- An assigned number is **fixed** for that publication throughout the whole work; cite its same number again wherever it occurs.
- Numbers are assigned in order of **first appearance in the body**.
- In the reference list (printed p. 19 / PDF 21), list citations in numeric order of first mention, and **do not group/sort by language or source type**. Each entry begins with its number.
- Where an author appears in a narrative, author name can be followed by numeric `[n]` as demonstrated on printed pp. 14–15.

## 2. Author–year system (ระบบนาม–ปี)
**RULE**, printed pp. 15–16 (PDF 17–18):
- Give author/group and publication year in text or parentheses, e.g. `Smith (1999)` or `(Smith, 1999)`.
- For multiple citations in one set of parentheses, separate using **semicolons** `;`.
- For a Thai-person author, use given name + surname when named; for non-Thai authors, generally use family name as a citation label.
- Three or more authors: use the first author's name with “et al.” for international names, or “และคณะ” in Thai, according to the manual's examples. See printed p. 16.
- If multiple works by one author share the year, use `a`, `b`, `c` after year for English; use `ก`, `ข`, `ค` for Thai (bibliography rule also printed p. 17).
- Year in Thai-cited Thai work: B.E.; foreign works: C.E. (printed p. 15).
- Direct short quotation: identify author, year and **page number**; enclose quoted words in quotation marks (printed p. 16).
- Long quotations: as shown on printed p. 16, use a visibly indented block approximately **5 characters from left and right** with tighter-than-normal line spacing. This is an approximate typographic instruction, not a precisely specified millimetre indention.

### Bibliography order for author–year
**RULE**, printed p. 22 (PDF 24):
- Sort bibliographic entries alphabetically by their author/title entry.
- For a **Thai-language thesis**, Thai-language bibliography comes **first**, then foreign-language bibliography.
- For an **English-language thesis**, English bibliography comes **first**, then Thai-language bibliography.
- Place each item's entry starting at the **left margin**. Do not impose numeric numbering on this list unless using numbered system.

## 3. Data fields by document type
The document's explicit pattern guide (printed pp. 17–19 / PDF 19–21) covers:

| Kind | Required details as described in manual |
|---|---|
| Book | author/editor; year; **book title**; edition if later than first; publisher; place of publication; referenced page(s) |
| Journal article | author; year; article title; **journal title**; volume; issue; page range |
| Conference proceeding | author; year; article title; conference title; occurrence/date/location; pages |
| Book chapter / article in edited book | author; year; article title; in book name; editor/compiler; edition; publisher/place; pages |
| Newspaper or magazine article | author; year; article title; publication title; date; pages |
| Thesis | author; year; title; degree/disciplines; faculty/department; university; relevant pages |
| Patent | owner; year granted; invention name; country and patent number |
| Full-text electronic journal | author; year; article title; journal name + [Electronic]; volume/issue/pages; availability/provider; retrieval date |
| Abstract database | author; year; abstract/article info; title/source; [Electronic]; availability/provider; retrieval date |
| Electronic journal | author; year; article title; journal [Electronic]; volume/issue/pages; availability; retrieval date |
| Web page | author; year; **Web Page Title**; `[Online]`; `Available: URL`; **retrieval date** |

**RULE:** Use actual verified publication details. When missing, flag `MISSING_REFERENCE_DATA` rather than manufacturing values; historic examples are not actual sources for a new thesis.

## 4. Sample patterns (illustrative only; fictitious placeholder data)

**Numbered, journal**:
`[1] Author, A., 2025, “Actual Article Title”, Journal Title, Vol. 10, No. 2, pp. 20–29.`

**Author–year journal**:
`Author, A., 2025, “Actual Article Title”, Journal Title, Vol. 10, No. 2, pp. 20–29.`

**Electronic page**:
`Author or Institution, year, Page Title [Online], Available: URL [retrieved date].`

These are merely **pattern scaffolds**; titles/years/etc must be taken from real sources and exact typographic punctuation may need review against printed pp. 17–23.

## 5. Reference auditing
- No citation marker is orphaned (its bibliography entry exists).
- No bibliography source is falsely created to fill a reference count.
- Numeric first-appearance sequence correct; all later mentions use original numbers.
- Author–year spellings, year suffixes, language grouping and bibliography entries match.
- All borrowed figures/tables have proper attribution, and title/author/year data are verified.
- Recheck italic/bold/title emphasis against source examples (printed pp. 19–23) rather than importing a conflicting citation standard silently.
