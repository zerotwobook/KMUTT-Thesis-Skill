## Source reliability limitations
1. This is a scanned file; automated text extraction returned no usable text. Page-by-page visual inspection is needed for any disputed punctuation or unusual requirement.
2. Manual date is Buddhist Era 2556 (2013 C.E.); no current policy verification has been performed by this offline skill.
3. The manual itself includes specimen chapter headings and historical sample materials, not actual thesis content. Don't mistake a specimen placeholder for a requirement.
4. `REFERENCES/FORMATS` are drawn from visual examination of the manual; where typesetting is unclear, inspect the referenced PDF page at 200–300 dpi.
